# Parcours utilisateur

Le parcours utilisateur est une représentation des étapes traversées par un usager pour atteindre son objectif avec un service. Il permet d'identifier les moments de friction, les opportunités d'amélioration et les priorités de conception.

!!! note

    Le parcours utilisateur s'appuie sur les enseignements de la [recherche utilisateur](ru.md). Il est réalisé avant le [story mapping](story-mapping.md), dont il constitue le matériau de base.

### Pourquoi cartographier le parcours utilisateur ?

* Donner une vision commune du vécu réel des usagers, au-delà des hypothèses de l'équipe
* Localiser les points de douleur et les étapes à fort enjeu pour l'expérience
* Préparer les décisions de conception et identifier ce qui doit entrer dans le [MVP](../cadrer/mvp.md)

**Point de contrôle :** une bonne cartographie est compréhensible par une personne extérieure au projet, sans explications orales.

### Quand mener l'atelier ?

* Après une première phase de [recherche utilisateur](ru.md) (entretiens, observations terrain)
* Avant le [story mapping](story-mapping.md), pour disposer d'une épine dorsale fondée sur le vécu réel

### Gabarit

| Étape | Actions de l'usager | Points de douleur | Opportunités |
|---|---|---|---|
| 1. [Titre de l'étape] | Ce que fait l'usager | Ce qui bloque ou frustre | Ce que le service pourrait mieux faire |
| 2. ... | | | |
| 3. ... | | | |

**Pour chaque étape, renseigner :**

* [ ] Titre de l'étape (court, du point de vue de l'usager)
* [ ] Actions concrètes réalisées
* [ ] Points de douleur (friction, incompréhension, délai, erreur)
* [ ] Opportunités d'amélioration

### Exemple

Parcours d'un agent souhaitant déclarer une inspection terrain.

| Étape | Actions | Points de douleur | Opportunités |
|---|---|---|---|
| 1. Préparer l'inspection | Consulte les dossiers existants dans plusieurs outils | Informations dispersées, aucun point d'entrée unique | Centraliser la consultation des dossiers |
| 2. Saisir le compte rendu | Remplit un formulaire papier sur le terrain | Ressaisie obligatoire au bureau, risque d'erreur | Formulaire numérique utilisable sur site |
| 3. Transmettre au service | Envoie le document par messagerie | Pas de confirmation de réception, suivi manuel | Envoi direct depuis l'outil, accusé automatique |
